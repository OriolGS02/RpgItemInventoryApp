\# RPG Item Inventory



A console application developed in C# to manage RPG items.



\## Features



\- Create items

\- Delete items

\- Search items

\- Edit items

\- Automatically generate item IDs

\- Save inventory data to JSON

\- Load inventory data from JSON



\## Technologies



\- C#

\- .NET

\- System.Text.Json



\## Project Structure



\- `Models` - Contains the item model.

\- `Services` - Contains the inventory logic and JSON persitence.

\- `Program.cs` - Handles the console menu and user interaction.





\## How to Run



1\. Clone the repository.

2\. Open the solution in Visual Studio.

3\. Build the project.

4\. Run the application.
